## Руководство по запуску

<br> Компилируем файлы на двух компьютерах, можно в пределах разных сетей.
<br> Запускаем server
<br> В другом терминале на этом же пк можем запускать client с локальным ip адрессом. Например, "./client 127.0.0.1 user1"
<br> На другом пк запускаем клиент с явно указанным ip адрессом машины, запустившей сервер. Например, "./client 192.168.42.1 user2"

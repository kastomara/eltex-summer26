Тема: Настройка протокола STP (IEEE 802.1D)
 
1) Для заданной на схеме schema-lab2 сети, состоящей из управляемых коммутаторов и персональных компьютеров настроить протокол STP, назначив явно один из коммутаторов корневым настройкой приоритета.

Настройка основного коммутатора (пусть будет коммутатор 2):
enable
configure terminal
spanning-tree mode rapid-prst
spanning-tree vlan 1 priority 4096
end
write memory

Настройка остальных коммутаторов:
enable
configure terminal
spanning-tree mode rapid-prst
end
write memory

Проверяем работу через show spanning-tree

5) Изменить стоимость маршрута для порта RP произвольного назначенного (designated) коммутатора, повторить действия из п.3, результат сохранить в отдельный файл

Установим для порта 0/2 первого коммутатора цену пути в 50.
vIOS-L2-01>enable
vIOS-L2-01#configure terminal
Enter configuration commands, one per line.  End with CNTL/Z.
vIOS-L2-01(config)#interface GigabitEthernet0/2
vIOS-L2-01(config-if)#spanning-tree vlan 1 cost 50
vIOS-L2-01(config-if)#end

Теперь выведем информацию.
vIOS-L2-01#show spanning-tree

VLAN0001
  Spanning tree enabled protocol ieee
  Root ID    Priority    4097
             Address     0c49.0843.0000
             Cost        4
             Port        4 (GigabitEthernet0/3)
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec

  Bridge ID  Priority    32769  (priority 32768 sys-id-ext 1)
             Address     0c6a.8ec1.0000
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec
             Aging Time  15  sec

Interface           Role Sts Cost      Prio.Nbr Type
------------------- ---- --- --------- -------- --------------------------------
Gi0/0               Desg FWD 4         128.1    Shr

Видим, что порт 0/2 BLK заблокирован из-за высокой цены пути, а другой порт 0/3 выбран в качестве альтернативы.

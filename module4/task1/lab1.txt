Лабораторная работа №1
1) Установить и настроить эмулятор GNS3

2) Создать простейшую сеть, состоящую из 1 коммутатора и 2 компьютеров, назначить им произвольные ip адреса из одной сети
Для того, чтобы назначить для компьютеров персональные ip адреса, заходим в консоль PC1 и PC2 и пишем следующее:

PC1> ip 192.168.1.1/24
Checking for duplicate address...
PC1 : 192.168.1.1 255.255.255.0

PC2> ip 192.168.1.2/24
Checking for duplicate address...
PC2 : 192.168.1.2 255.255.255.0

В данном варианте адреса находятся в одной подсети 192.168.1.X. Последний октет задает устройство.

5) Создать простейшую сеть, состоящую из 1 маршрутизатора и 2 компьютеров, назначить им произвольные ip адреса из разных сетей

PC3> ip 192.168.1.24
Checking for duplicate address...
PC3 : 192.168.1.24 255.255.255.0

PC4> ip 223.0.3.64
Checking for duplicate address...
PC4 : 223.0.3.64 255.255.255.0

Настройка маршрутизатора:
ESW1# enable
ESW1#configure terminal
ESW1(config)#interface FastEthernet0/1
ESW1(config-if)#ip address 192.168.1.24 255.255.255.0
ESW1(config-if)#no shutdown
ESW1(config-if)#
*Mar  1 00:11:20.439: %LINK-3-UPDOWN: Interface FastEthernet0/1, changed state to up
*Mar  1 00:11:21.439: %LINEPROTO-5-UPDOWN: Line protocol on Interface FastEthernet0/1, changed state to up
ESW1(config-if)#exit
ESW1(config)#interface FastEthernet0/0          
ESW1(config-if)#ip address 223.0.3.64 255.255.255.0
ESW1(config-if)#no shutdown                        
ESW1(config-if)#

*Mar  1 00:17:07.867: %LINEPROTO-5-UPDOWN: Line protocol on Interface FastEthernet0/0, changed state to up
ESW1(config-if)#exit

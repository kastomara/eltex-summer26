Собираем и загружаем модуль. Можно сделать через:
```
make mode
```
<br> Попробуем отправить сообщение ядру. Для этого нужно запустить make 1 (ввести собственное сообщение) или 10 (заготовленное). Доступен ввод в 2 вариантах:
```
./user 
./user "Сообщение"
```
<br>Выводим сообщения ядру через:
```
sudo dmesg
```
